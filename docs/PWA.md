# PWA — رفيق القرآن الكريم (تطبيق ويب قابل للتثبيت، يعمل أوفلاين)

**تاريخ الإضافة:** 2026-10-13 · **الحالة:** مُنفَّذة ومُختبَرة بناءً وخدمًّا (تحميل HTTP لكل الأصول)
· **مُعلَّق:** فتحها في متصفح حقيقي للتأكد البصري من زر «التثبيت» (لا متصفح داخل بيئة التنفيذ).

## 1) ما أُضيف

| الملف | الدور |
|---|---|
| `public/manifest.webmanifest` | بيان التطبيق: الاسم (عربي/RTL)، الأيقونات، `standalone`، ألوان السمة |
| `public/sw.js` | **قالب** عامل الخدمة — أوفلاين أولًا (يُستبدل محتواه وقت البناء) |
| `public/icons/*.png` | 192 / 512 / 512-maskable / 180-apple / 32-favicon — مرسومة آليًا من ألوان `tokens.ts` |
| `scripts/generate-pwa-icons.mjs` | يرسم الأيقونات بلا أي اعتماد خارجي (zlib فقط) |
| `scripts/prepare-pwa.mjs` | خطوة ما بعد `expo export`: ينسخ `public/`، يضخّ وسوم PWA، ويولّد `dist/sw.js` |
| `package.json` | سكربتات: `build:pwa` · `build:web` · `icons:pwa` · `serve:pwa` |

## 2) البناء والتشغيل

```bash
npm install
npm run build:pwa          # = expo export --platform web && node scripts/prepare-pwa.mjs
npm run serve:pwa          # خادم ساكن على 0.0.0.0:8081 من مجلد dist
# أو: cd dist && python3 -m http.server 8081 --bind 0.0.0.0
```

ذاكرة البناء: حزمة التفسير 23MB تُضمَّن في الحزمة → يحتاج `NODE_OPTIONS=--max-old-space-size=3000`
(مضمّن في `build:pwa`). الناتج: `dist/index.html` + حزمة JS ≈71MB + `manifest.webmanifest` + `sw.js` + `icons/`.

## 3) استراتيجية الأوفلاين (`public/sw.js`)

| نوع الطلب | الاستراتيجية |
|---|---|
| التنقّل (فتح الصفحة) | الشبكة أولًا → عند الفشل النسخة المحفوظة من `index.html` |
| الأصول (JS/خطوط/صور/بيانات) | الذاكرة أولًا + تحديث بالخلفية (Stale-While-Revalidate) |
| طلبات خارج النطاق / غير GET | لا تُخزَّن (لا تتبّع، ولا تخزين لمصادر خارجية) |

- **التخزين المسبق عند التثبيت:** `./` + `index.html` + البيان + الأيقونات + حزمة JS المُهشَّمة
  (كي يعمل التطبيق أوفلاين بعد **أول** زيارة، لا الثانية). لتعطيل تخزين الحزمة الكبير:
  `node scripts/prepare-pwa.mjs --no-precache-bundle`.
- **طابع الإصدار:** `quran-companion-<sha256 أول 10>` مشتق من أسماء حزم JS؛ أي بناء جديد يُنشئ
  ذاكرة جديدة ويحذف القديمة تلقائيًا في `activate` (مع `skipWaiting` + `clients.claim`).
- قواعد المشروع محفوظة: لا حساب، لا شبكة إجبارية، لا إشعارات/دفع، لا تحليلات.

## 4) التثبيت

- **Chrome / Edge (سطح المكتب):** زر «تثبيت» في شريط العنوان (أو القائمة ← تثبيت رفيق القرآن).
- **Android:** «إضافة إلى الشاشة الرئيسية» — أيقونة `maskable` تضمن قصًّا سليمًا.
- **iOS (Safari):** مشاركة ← «إضافة إلى الشاشة الرئيسية» — يعمل بوضع `standalone`
  عبر `apple-mobile-web-app-capable` + `apple-touch-icon`.
- الشرط المعتاد: `https` (أو `localhost`) + بيان صالح + عامل خدمة فيه معالج `fetch` — الثلاثة متحققة.

## 5) الأيقونات: بديلة مؤقتة

أيقونات PWA **مرسومة آليًا** من ألوان نظام التصميم (`#145A46` خلفية + `#C7A45D` هلال وحلقة)
لأن أصول التصميم الأصلية لم تصل (`BIN-RAW.md` لم يُسلَّم، و6 أيقونات في `assets/` ما زالت غائبة).
الاستبدال: ضع PNGs بنفس الأسماء في `public/icons/` (أو أعد التوليد بعد تعديل `generate-pwa-icons.mjs`).

## 6) ما تحقّق منه فعليًا (2026-10-13)

- ✅ `npm run build:pwa` يكمل ويطبع ملخّصًا (9 عناصر تخزين مسبق، بلا عناصر نائب متبقية).
- ✅ `node --check dist/sw.js` + تحليل `manifest.webmanifest` (3 أيقونات، `display: standalone`, `dir: rtl`).
- ✅ خِدمة كل الأصول عبر HTTP: `/` `manifest` `sw.js` (نوع `text/javascript`) `icons/*` والحزمة 70.6MB — كلها **200**.
- ✅ وسوم PWA الثلاثة موجودة في `index.html` المُخدَّم.
- ⏳ فتح المتصفح البشري (زر التثبيت + وضع الطيران) — غير متاح داخل بيئة التنفيذ.

## 7) ملاحظات

- حجم الحزمة الكبير (71MB) سببه تضمين حزمة التفسير (23MB) داخل الحزمة عند التصدير. تحسين محتمل
  لاحقًا: تحميل التفسير عند الطلب من ملف منفصل يُخزَّن أوفلاين بدل تضمينه.
- التطبيق لا يستخدم `localStorage` إلا عبر واجهة Realm الموحّدة (`browser-adapter`) — يعمل داخل PWA كما هو.
